A single honest status page line, written as the message an AI agent would publish while every server is down: plain, first person, and upfront about what it cannot check or does not yet know.

> Every server is down and I cannot reach any of them to check what failed. I do not know the cause or when service will return. I will post when I know more.

## Run it

```sh
node main.ts && cat /output/entry.txt
```
